# سجل الفواتح IBRA

تطبيق لتسجيل أهل الفضل في الفواتح: الاسم، رقم الموبايل، المبلغ، نوع الفضل، القرابة (قريب فلان…)، المنطقة والملاحظات — حتى ترد الجميل لكل شخص مستقبلاً.

## المزايا
- فواتح متعددة، وكل فاتحة لها سجلها ومجموعها
- بحث سريع، وفلترة: بانتظار الرد / تم الرد
- قسم **رد الجميل**: ابحث عن الشخص لتعرف ماذا قدّم ومتى، وسجّل ردّك (المبلغ والتاريخ والمناسبة)
- اتصال وواتساب مباشر من السجل
- طباعة السجل جدولاً مرتباً مع المجموع، وحفظه PDF
- نسخ احتياطي واستيراد مع الدمج لنقل البيانات بين الحاسبة والموبايل، وتصدير Excel
- يعمل بدون إنترنت، عربي بالكامل

## المنصات
| المنصة | الملف |
|---|---|
| ويندوز | `IBRA-Fawateh-x.x.x-x64-nsis.exe` (تنصيب) و `-portable.exe` |
| أندرويد | `IBRA-Fawateh-x.x.x.apk` |
| آيفون | `IBRA-Fawateh-x.x.x-unsigned.ipa` (يوقّع بالشهادة الشخصية) |

الملفات تُبنى تلقائياً بـ GitHub Actions مع كل دفع إلى `main` وتُنشر في Releases.

## التطوير
```bash
npm install
npm start            # تشغيل نسخة الحاسبة
npm run dist:win     # بناء EXE
npm run android      # إنشاء مشروع أندرويد
npm run ios          # إنشاء مشروع آيفون (ماك)
```
لتحديث الإصدار غيّر `version` في `package.json`.
