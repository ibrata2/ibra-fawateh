## 💡 فكرة التطبيق

في مجتمعنا العراقي، الفاتحة مو بس مناسبة عزاء؛ هي وقفة ناس. يجيك القريب والجار والصديق وزميل الشغل، وكل واحد يقدّم شي: مبلغ مالي يخفف المصاريف عن أهل المتوفى، ذبيحة، طعام، خدمة بالجامع أو الحسينية، أو حتى حضوره ووقفته ثلاث أيام.

وبعد الفاتحة تبقى مشكلة يعرفها الكل: **الأسماء تضيع**. الدفتر الورقي يتلف أو ينفقد، الذاكرة تخون، وبعد سنة أو سنتين يصير عند واحد من هذولاك الناس فاتحة أو مناسبة، وما تتذكر هل وقف وياك؟ شكد قدّم؟ منو هو بالضبط — "ابن عم فلان لو صديق أبو علي؟".

**سجل الفواتح IBRA** يحل هذي المشكلة: تسجّل كل شخص وقف وياك — اسمه، رقم موبايله، المبلغ أو نوع الفضل، وتعريفه (قريب فلان، جار، صديق المرحوم…) — وتبقى المعلومات محفوظة ومرتبة سنين. ولمن يجي وقت ردّ الجميل، تكتب اسمه وتعرف كل شي بثواني، وتسجّل إنك رديت الجميل.

## 🤝 فائدته للمجتمع

- **حفظ الحقوق والوفاء**: رد الجميل من أصالة مجتمعنا وقيمه. التطبيق يضمن ما ينسى أحد فضل أحد، ولا يضيع حق أي شخص وقف بوقت الشدة.
- **تقوية صلة الرحم والعلاقات**: لمن ترد الجميل بوقته، تبقى العلاقات بين العوائل والجيران والأصدقاء قوية ومتبادلة.
- **إنهاء الإحراج**: ما تحتاج تسأل "إنت منو؟" أو "شكد جبت؟". كل شي مسجل باحترام وخصوصية.
- **التكافل الاجتماعي**: الفاتحة نظام تكافل؛ الناس تساند بعضها بالمصاريف. التسجيل المرتب يخلي هذا التكافل مستمر وعادل بين الكل.
- **بديل الدفتر الورقي**: بدل الدفتر اللي يتلف أو يضيع أو خطه ما ينقرا، سجل إلكتروني مرتب مع بحث ونسخة احتياطية.
- **راحة لأهل المتوفى**: بأيام الحزن الناس ما عندها بال للحسابات. واحد من الأهل يسجّل بسرعة من موبايله، وبعدين يطبعون السجل كامل بالمجموع.
- **يناسب الكل**: عربي بالكامل، سهل، يشتغل بدون إنترنت، ومجاني.

> وتقدر تستخدمه لأي مناسبة ثانية فيها "واجب" متبادل: أعراس، مواليد، عمليات، رجعة من الحج… أي وقت الناس وقفت وياك وتريد ترد وقفتهم.

## المزايا
- فواتح متعددة، وكل فاتحة لها سجلها ومجموعها
- بحث سريع، وفلترة: بانتظار الرد / تم الرد
- قسم **رد الجميل**: ابحث عن الشخص لتعرف ماذا قدّم ومتى، وسجّل ردّك (المبلغ والتاريخ والمناسبة)
- اتصال وواتساب مباشر من السجل
- طباعة السجل جدولاً مرتباً مع المجموع، وحفظه PDF
- نسخ احتياطي واستيراد مع الدمج لنقل البيانات بين الحاسبة والموبايل، وتصدير Excel
- يعمل بدون إنترنت، عربي بالكامل

## المنصات
| المنصة | الملف |
|---|---|
| ويندوز | `IBRA-Fawateh-x.x.x-x64-nsis.exe` (تنصيب) و `-portable.exe` |
| أندرويد | `IBRA-Fawateh-x.x.x.apk` |
| آيفون | `IBRA-Fawateh-x.x.x-unsigned.ipa` (يوقّع بالشهادة الشخصية) |

الملفات تُبنى تلقائياً بـ GitHub Actions مع كل دفع إلى `main` وتُنشر في Releases.

## التطوير
```bash
npm install
npm start            # تشغيل نسخة الحاسبة
npm run dist:win     # بناء EXE
npm run android      # إنشاء مشروع أندرويد
npm run ios          # إنشاء مشروع آيفون (ماك)
```
لتحديث الإصدار غيّر `version` في `package.json`.
